# 🌐 تطبيق المحادثة الفورية (Real-Time Chat & Video Call App)

تطبيق ويب متكامل للمحادثة الفورية يدعم المراسلة النصية، المكالمات الصوتية، ومكالمات الفيديو في الوقت الفعلي (Real-Time) باستخدام تقنيات **Socket.io** و **WebRTC**. يتميز التطبيق بواجهة مستخدم متجاوبة تماماً، بالإضافة لدعمه لتطبيقات الويب التقدمية (PWA) مما يتيح للمستخدمين تثبيته على أجهزتهم كأي تطبيق عادي.

---

## ✨ المميزات (Features)

- 💬 **مراسلة نصية فورية:** تواصل سريع وبدون تأخير مع دعم مدمج لإرسال الإيموجيز (Emojis).
- 📹 **مكالمات فيديو وصوت:** اتصال مباشر بين طرفين (Peer-to-Peer) باستخدام WebRTC.
- 🔐 **غرف محادثة خاصة:** نظام غرف معزولة يعتمد على أكواد فريدة لكل جلسة لضمان الخصوصية.
- 📱 **واجهة متجاوبة (Responsive):** تصميم مرن يتوافق مع جميع الشاشات (الهواتف، الأجهزة اللوحية، الحواسيب) باستخدام Bootstrap 5.
- 📲 **تطبيق ويب تقدمي (PWA):** إمكانية تثبيت التطبيق مباشرة على الهاتف أو سطح المكتب بضغطة زر.
- 🔗 **مشاركة سهلة:** زر مشاركة مدمج يعتمد على (Web Share API) لمشاركة التطبيق مع الأصدقاء.
- 🎨 **تجربة مستخدم محسنة:** إشعارات عند انضمام مستخدمين جدد، ونسخ سريع لكود الغرفة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

### الواجهة الأمامية (Front-end)
* HTML5 / CSS3 / JavaScript (Vanilla)
* [Bootstrap 5](https://getbootstrap.com/) & Bootstrap Icons
* WebRTC API (للمكالمات)
* PWA (Manifest & Service Worker)

### الواجهة الخلفية (Back-end)
* [Node.js](https://nodejs.org/)
* [Express.js](https://expressjs.com/) (لإدارة الخادم)
* [Socket.io](https://socket.io/) (للمزامنة في الوقت الفعلي)
